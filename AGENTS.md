# Zenable Labs

Commit with conventional commits scoped to the lab directory — `fix(a2a): ...`, `docs(acp-goose): ...`, `feat(ema-mcp): ...` — and drop the scope only for repo-wide changes.

Readers clone this repo and run it live from the matching Zenable Learning Hub unit, so a change here reaches them with no Learning Hub deploy: run what you touched before you push.
